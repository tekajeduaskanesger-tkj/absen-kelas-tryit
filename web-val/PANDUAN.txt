# 💖 Website Surprise Valentine - Panduan Penggunaan

Selamat! Kamu sudah punya website surprise Valentine yang romantis! 

## 📁 File yang Ada:
1. **index.html** - File utama website
2. **style.css** - File styling dan animasi
3. **script.js** - File logika dan interaksi

## 🎯 Cara Menggunakan:

### 1. Persiapan Awal
- Simpan ketiga file (index.html, style.css, script.js) dalam satu folder
- Pastikan nama file tetap sama seperti di atas

### 2. Memasukkan Foto
Ada 2 cara untuk memasukkan foto:

**Cara A - Ganti dengan foto kalian (Recommended):**
1. Buka file `index.html`
2. Cari bagian `<div class="photo-placeholder">` (ada 6 tempat)
3. Ganti dengan kode ini:

```html
<div class="photo-item">
    <img src="foto1.jpg" alt="Foto 1" style="width: 100%; height: 300px; object-fit: cover;">
</div>
```

4. Simpan foto-foto kalian dengan nama: foto1.jpg, foto2.jpg, dst. di folder yang sama
5. Ganti "foto1.jpg" dengan nama file foto kalian

**Cara B - Gunakan link foto online:**
```html
<div class="photo-item">
    <img src="https://link-foto-kalian.com/foto.jpg" alt="Foto 1" style="width: 100%; height: 300px; object-fit: cover;">
</div>
```

### 3. Memasukkan Lagu/Musik

**Cara A - File musik lokal:**
1. Simpan file musik kalian (format .mp3) di folder yang sama
2. Buka `index.html`
3. Cari bagian `<audio id="bgMusic">`
4. Ganti "your-song.mp3" dengan nama file musik kalian:

```html
<audio id="bgMusic" controls>
    <source src="nama-lagu-kalian.mp3" type="audio/mpeg">
</audio>
```

**Cara B - Link musik online:**
```html
<audio id="bgMusic" controls>
    <source src="https://link-musik-kalian.com/song.mp3" type="audio/mpeg">
</audio>
```

### 4. Mengubah Jawaban Teka-Teki
1. Buka file `script.js`
2. Cari baris: `const correctAnswer = "14/02/2024";`
3. Ganti dengan tanggal kalian bertemu (format: DD/MM/YYYY)
4. Contoh: `const correctAnswer = "25/12/2023";`

### 5. Personalisasi Pesan Valentine
Buka `index.html` dan cari bagian `<div class="valentine-message">`:

**Yang bisa diganti:**
- Ucapan Valentine
- Kata-kata romantis
- Quote cinta
- Signature/tanda tangan

Contoh:
```html
<p class="love-quote">
    "Ganti dengan kata-kata romantis kalian sendiri<br>
    Bisa beberapa baris<br>
    Sesuka hati kalian!"
</p>
```

### 6. Mengubah Pertanyaan Teka-Teki
Di file `index.html`, cari bagian:
```html
<p class="question">💭 Tanggal berapa kita pertama kali bertemu?</p>
```

Ganti dengan pertanyaan kalian sendiri seperti:
- "Apa makanan favorit aku?"
- "Di mana kita kencan pertama kali?"
- "Apa film yang pertama kali kita tonton bersama?"

(Jangan lupa update jawaban di `script.js` juga!)

## 🚀 Cara Menjalankan Website:

### Opsi 1 - Langsung di Browser (Paling Mudah):
1. Double-click file `index.html`
2. Website akan terbuka di browser
3. Siap untuk di-share ke pacar!

### Opsi 2 - Upload ke Hosting Gratis:
Bisa upload ke:
- GitHub Pages (gratis)
- Netlify (gratis)
- Vercel (gratis)

Untuk GitHub Pages:
1. Buat repository baru di GitHub
2. Upload ketiga file
3. Settings > Pages > Deploy
4. Dapat link: username.github.io/nama-repo

## 💡 Tips & Trik:

1. **Test dulu sebelum dikasih ke pacar!**
   - Cek semua foto muncul
   - Cek musik bisa diplay
   - Cek teka-teki berfungsi

2. **Format Foto Terbaik:**
   - Gunakan foto landscape (horizontal)
   - Resolusi: 1200x800 px (optimal)
   - Format: JPG atau PNG
   - Ukuran: < 2MB per foto (biar cepat load)

3. **Format Musik:**
   - Format .mp3 (paling compatible)
   - Ukuran: < 10MB (biar cepat load)
   - Jika file besar, potong/kompres dulu

4. **Browser Terbaik:**
   - Chrome ✅
   - Firefox ✅
   - Safari ✅
   - Edge ✅

## ⚠️ Troubleshooting:

**Musik tidak autoplay?**
- Normal! Browser modern memblokir autoplay
- Pacar harus klik tombol play
- Ini untuk keamanan browser

**Foto tidak muncul?**
- Cek nama file foto sudah benar
- Cek foto ada di folder yang sama
- Cek format foto (JPG/PNG)

**Animasi patah-patah?**
- Cek koneksi internet
- Tutup tab browser lain
- Refresh halaman (F5)
